Permite que un asistente de IA (como Antigravity, Claude Desktop o Cursor) se conecte directamente a tu dispositivo móvil o PC para inspeccionar errores, leer logs donde no hay terminal, y reparar extensiones fallidas.

Endpoint MCP Nativo Servidor Activo :45731

En Android móvil, cualquier IA o PC en la misma red Wi-Fi puede acceder cambiando localhost por la IP local de tu celular.

¿Una extensión falló o tiene un reproductor bloqueado?

Si un sitio tiene protecciones JS o Cloudflare especiales que el motor determinista no pudo resolver, copia el reporte de diagnóstico generado arriba y compártelo con tu IA, o aplica directamente el parche sugerido.

Servidor API Embebido (Para Celular & PC)

Como en Android no hay terminal de línea de comandos, AEXT levanta un servidor HTTP nativo en Rust para comunicarse con Nekoyomi y servir descargas directamente.
