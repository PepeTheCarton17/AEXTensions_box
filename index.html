¿Una extensión falló o tiene un reproductor bloqueado?

Si un sitio tiene protecciones JS o Cloudflare especiales que el motor determinista no pudo resolver, genera el reporte de diagnóstico o aplica un parche manual de selectores o código Kotlin. Cada parche crea una copia de seguridad restaurable.

Versiones del código (original y modificada)

Antes de cada parche se guarda una copia del código. Puedes restaurar la versión original o cualquier estado anterior.

Motores instalables

Cuando una portada no expone catálogo HTML, AEXT prueba motores compatibles con peticiones anónimas. Los motores se instalan desde un repositorio que publica aext-engine.json con licencia y procedencia; se conservan al actualizar extensiones.

Servidor API local (móvil y PC)

En Android no siempre hay terminal, así que AEXT levanta un servidor HTTP nativo en Rust para comunicarse con Nekoyomi y servir descargas directamente.
